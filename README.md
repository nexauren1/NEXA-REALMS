# NEXA REALMS

NEXA REALMS is a hand-coded top-down 2D adventure built with Phaser 4 and packaged for Android with Capacitor 8.

## First playable chapter — v0.1.0

The game uses original code-drawn visuals: characters, trees, buildings, paths, Lumen Stones, enemies and the Rift Sanctuary are generated by code.

### World map

Dawn Village is the central hub. Nova's Map Room is north-east of the village, Kai's Camp is south-west, and Zara's Archive is south-east. The roads lead to the three objectives:

- Whispering Grove — western objective; first Lumen Stone.
- Moonwater Lake — southern objective; second Lumen Stone on the north shore.
- Ember Ridge — eastern objective; third Lumen Stone.
- Rift Gate — northern landmark; opens when all three stones are restored.
- Rift Sanctuary — first dungeon; three anchors awaken the Guardian, then Kysam restores the Core.

### Characters

- Kysam — main playable character, The Resonant.
- Nova — mapkeeper and first guide.
- Kai — trail scout and route guide.
- Zara — archivist and lore keeper.

### Gameplay systems

Exploration, touch controls, keyboard controls, NPC dialogue, objectives, collectible world progress, XP, levels, Resonance Pulse, enemies, dungeon anchors, a Guardian encounter, local save and chapter completion are included.

### Controls

Keyboard: WASD or arrow keys to move, E to interact, Space to use Resonance Pulse.
Mobile: on-screen movement controls, E interaction and PULSE action.

### GitHub build

The GitHub Actions workflow builds the web game, creates the Android project with Capacitor, compiles a debug APK and uploads it as a workflow artifact. The first successful build also creates the v0.1.0 GitHub Release and attaches app-debug.apk.

### Research basis

The implementation is based on current Phaser 4 documentation and examples for 2D scenes, input, cameras, tweens and code-driven rendering, plus broad conventions visible in small 2D RPGs: a central hub, connected routes, landmarks, NPC guidance, gated progression and a dungeon. No third-party game art is bundled into this version.
